# Livrable 2 - Preuve de concept de scraping

Une fois votre inventaire du livrable 1 terminé, choisissez **au moins un site** parmi ceux recensés. Le but est de comprendre comment en extraire des offres d’emploi ou de stage et de voir ce qui facilite ou complique la collecte.

## Volet 1 - Créer un prototype

Écrivez un petit script, idéalement en **Python**, qui tente d’extraire automatiquement des données de la page d’offres du site choisi. Commencez par une page et quelques champs, par exemple le titre du poste, le nom de l’employeur ou le lien vers l’offre. Comparez un échantillon de vos résultats avec les offres affichées sur le site pour vérifier ce que le script récupère réellement.

Vous pouvez utiliser un assistant de code, une autre IA ou les outils de votre choix. Soyez en mesure d’expliquer comment votre script récupère la page et repère les données à extraire.

Un essai sur un seul site suffit. Vous pouvez ensuite tester la même approche sur d’autres sites et observer ce qui doit être adapté.

## Volet 2 - Documenter les essais

Rédigez un court compte rendu en Markdown. Indiquez les éléments suivants.

- Le nom du site et l’URL de la page testée.
- La méthode et les outils utilisés, ainsi que la commande pour lancer le prototype et les dépendances éventuelles.
- Les données que vous avez réussi à récupérer, avec un petit exemple si vous avez obtenu des résultats.
- Ce qui a mal fonctionné ou bloqué, les limites que vous avez observées et les pistes que vous avez essayées.

Si la collecte ne donne aucun résultat, décrivez ce que vous avez tenté et ce que vous avez observé.

## Déposer votre contribution

Publiez le code et le compte rendu dans votre dossier personnel `equipe/votre-nom/02-preuve-de-concept-scraping/` sur le [dépôt GitHub du projet](https://github.com/chergreg/jobs-insights). Nous mettrons ensuite les prototypes et les observations en commun pour comparer les approches.
